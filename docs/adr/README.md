# Architecture decision records

Each record captures one decision that shapes how Spine is built or written.
Records are numbered in order and never renumbered. To change a decision,
add a new record and mark the old one superseded.

Name a record `NNNN-short-title.md` and give it these sections:

- **Status**: proposed, accepted, superseded by NNNN, or withdrawn.
- **Date**: the day the status last changed, as YYYY-MM-DD.
- **Context**: the problem and the constraints that bear on it.
- **Decision**: what was chosen, stated so it can be checked.
- **Consequences**: what follows, including the costs.
